# 🌍 LingoHub Ecosystem (React & Flutter)

An AI-powered, multi-language learning ecosystem featuring dynamic lesson generation, vocabulary tracking, and interactive audio drills across Web (React) and Mobile/Desktop (Flutter).

## 📁 Repository Structure

```text
Language-Learning-React-Apps/
├── react-app/       # Web application built with React + Vite + Tailwind CSS
└── flutter-app/     # Mobile & Cross-platform app built with Flutter + Dart
```

## 🚀 Getting Started

### 1. React Web App (`react-app/`)
```bash
cd react-app
npm install
npm run dev
```

### 2. Flutter App (`flutter-app/`)
```bash
cd flutter-app
flutter pub get
flutter run
```

---

## 🧰 Tech Stack & Architecture

- **React Web App (`react-app/`)**: Built with React, Vite, Tailwind CSS, Firebase Firestore & Auth, and Gemini API.
- **Flutter App (`flutter-app/`)**: Built with Flutter, Provider, Material 3, Firebase, and Gemini API.
